# 使用指南

这不是单纯的“八股题库”。每个专题尽量同时覆盖底层原理、生产实践、异常路径、容量与监控、面试速答和连续追问。

## 推荐入口

- [学习路线](./learning-path.md)：按目标和时间选择阅读顺序。
- [迁移清单](../migration-manifest.md)：查看源资料与目标章节的对应关系。

## 如何判断内容可信度

首先查看页面顶部的 `status` 和 `baseline`。`verified` 表示已完成版本与事实校准；`reviewing` 表示内容已经结构化，但参数或版本仍需复核；`legacy` 只解释历史行为。

## 面试使用方式

先背“一句话结论”和“90 秒回答”，再用原理、异常路径和取舍应对追问。项目案例中的规模与指标必须明确说成个人项目口径，不能包装成通用结论。
