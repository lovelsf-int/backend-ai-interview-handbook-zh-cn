# 缓存穿透、击穿与雪崩

## 第五章 缓存三大问题：穿透、击穿、雪崩（P7业务核心）

### 5.1 缓存穿透

**问题**：查询数据库不存在的Key，缓存永远不命中，请求直接打穿DB，压垮数据库。

**解决方案**：

缓存空值/默认值，设置短TTL

**布隆过滤器**前置过滤无效Key

接口参数校验、黑名单拦截

### 5.2 缓存击穿

**问题**：**热点Key**过期瞬间，海量请求同时穿透到DB。

**解决方案**：

热点Key永不过期

互斥锁（单线程更新缓存）

后台异步续期热点Key

### 5.3 缓存雪崩

**问题**：大量缓存Key同时过期 / Redis宕机，流量全部击穿DB，引发级联崩溃。

**解决方案**：

TTL添加随机偏移量，避免批量过期

热点数据永久缓存

Redis集群高可用、主从兜底

接口限流、熔断、降级兜底
